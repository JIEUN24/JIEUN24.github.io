# 실전프로젝트 MVP 기능 구현

실전 프로젝트를 시작한지 2주차가 되면서 기본적인 **MVP 기능에 대한 구성이 어느정도 자리잡혔다**. MVP 기간을 설정하고 프론트와 디자이너의 협업, 백엔드와의 소통 등의 다양한 과정을 거치며 구현해야하는 기능들을 하나씩 완성해나가고 있다.

특히 이번 주차에서는 오디오북 서비스의 핵심인 **오디오 플레이어 기능**을 구현하면서 react-h5-audio-player 라이브러리를 활용한 경험과 발생한 문제들을 해결하는 과정에서 많은 것을 배울 수 있었다.

## 프로젝트 EYAGI - 오디오북 플랫폼

### 프로젝트 개요
**서비스명:** EYAGI(이야기)
**프로젝트 기간:** 2022.04.21 ~ 2022.06.02 (총 6주간)
**팀 구성:** 백엔드 3명, 프론트엔드 2명, 디자이너 2명

EYAGI는 사용자가 오디오북을 듣고, 펀딩에 참여하며, 크리에이터와 소통할 수 있는 종합 오디오북 플랫폼이다.

## 구현해야할 페이지 및 MVP 기능

### 주요 페이지
- 메인, 회원가입, 로그인, 마이페이지
- 책 목록, 책 상세, 펀딩 목록, 펀딩 상세, 펀딩 등록
- 오디오북 등록, 오디오 상세, 1:1 채팅 페이지
- 오디오북 요청하기, 판매자 상세페이지

### MVP 기능
- **메인**: 카테고리별 도서, 오늘의 크리에이터, 추천도서, 랜덤 오디오펀딩 get
- **로그인 & 회원가입**: 로그인 회원가입 유효성 검사, 중복확인, 로그인 유지
- **책 목록 & 책 상세**: 카테고리별 도서 get, 책 상세페이지에서 오디오 미리듣기 제공, 팔로우, 오디오북 요청 CRUD, 오디오북 등록 CR, 펀딩 등록 CR
- **오디오 상세**: 목차별 오디오 재생목록 출력, 재생목록 클릭시 각 목차 재생, 후기 CRUD
- **펀딩**: 펀딩 등록 CR, 펀딩 좋아요, 펀딩 목록 get
- **마이페이지**: 프로필 등록 및 수정, 판매자 목소리 등록, 내가 등록한 펀딩, 오디오북, 내가 찜한 책 get
- **크리에이터 상세페이지**: 팔로우, 언팔로우 기능, 판매자가 등록한 펀딩과 책 get
- **채팅**: 1:1 채팅

## react-h5-audio-player를 활용한 오디오 플레이어 구현

### 라이브러리 선택 이유

오디오북 서비스의 핵심인 오디오 플레이어 구현을 위해 **react-h5-audio-player** 라이브러리를 선택했다. 이 라이브러리를 선택한 이유는 다음과 같다:

- **React 환경에 최적화**: React 컴포넌트로 쉽게 통합 가능
- **풍부한 기능**: 재생, 일시정지, 진행률 바, 볼륨 조절 등 기본 기능 제공
- **커스터마이징 가능**: CSS를 통한 스타일 변경 용이
- **반응형 지원**: 다양한 화면 크기에 대응

### 오디오 플레이어 기본 구현

```javascript
import AudioPlayer from "react-h5-audio-player";

// 기본 오디오 플레이어 구현
<AudioPlayer
  className="audio"
  ref={player}
  src={audioUrl}
  onPlay={() => console.log("재생 시작")}
  onPause={() => console.log("재생 일시정지")}
  // 추가 설정들...
/>
```

## 기술적 도전과 해결: 자동재생 문제

### 문제 상황

프로젝트를 진행하면서 **심각한 버그**를 발견했다. 오디오를 등록한 후 페이지 이동 후 렌더링이 될 때 **모든 플레이어의 음악이 자동재생되는 문제**가 발생한 것이다.

이는 사용자 경험에 치명적인 문제였다:
- 예상치 못한 소음으로 인한 사용자 불편
- 여러 오디오가 동시 재생되어 혼란 야기
- 데이터 사용량 증가

### 해결 시도 과정

#### 1차 시도: autoplay 속성 활용
```javascript
<AudioPlayer
  autoPlay={false}  // 자동재생 비활성화 시도
  // ... 기타 설정
/>
```

하지만 react-h5-audio-player에서 제공하는 `autoPlay` 속성이 예상대로 작동하지 않았다.

#### 2차 시도: useRef와 useEffect 활용한 해결

문제를 해결하기 위해 **React Hooks를 활용한 접근법**을 시도했다:

```javascript
import React, { useEffect, useRef } from 'react';
import AudioPlayer from "react-h5-audio-player";

const MyPage = () => {
  // 플레이어 참조를 위한 useRef
  const player = useRef();
  
  // 렌더링 시 자동재생 방지
  useEffect(() => {
    if (authority === "ROLE_SELLER") {
      player.current.audio.current.pause();  // 강제로 일시정지
    }
  }, [profile]);

  return (
    <AudioPlayer
      className="audio"
      ref={player}  // ref 연결
      src={voiceUrl}
      // ... 기타 설정
    />
  );
};
```

### 해결 방법의 핵심

1. **useRef 활용**: 오디오 플레이어 DOM 요소에 직접 접근
2. **useEffect 활용**: 컴포넌트 렌더링 시점에 제어
3. **직접 제어**: `player.current.audio.current.pause()`로 강제 일시정지

이 방법을 통해 **렌더링 시 자동재생 문제를 완전히 해결**할 수 있었다.
